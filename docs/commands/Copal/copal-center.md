# command:  copal-center
# purpose:  One window listing the whole catalogue, installed or not, with the action for each.
# why:      Super+Shift+C: the catalogue at a glance. It opens Copal Apps where
#           that exists, and the store's own window where it does not.
# see:      copal-apps, copal-store, copal-install

## Use
Open it with Super+Shift+C or by name. Each row is a program with its
status and section; choosing one runs it if installed, or installs it.

## Examples
    copal-center                         # the catalogue window

## Options
(none)

## Notes
- It is the older window of the two; Copal Apps (`copal-apps`) is the
  richer one, and copal-center hands over to it where it is installed.
