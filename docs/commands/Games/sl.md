# command:  sl
# purpose:  A steam locomotive crosses the screen -- for when you typed sl instead of ls.
# why:      One of the catalogue's toys: the classic punishment for a typo.
#           It cannot be interrupted, which is the point.
# see:      cmatrix, asciiquarium

## Use
Mistype `ls` as `sl`, and wait.

## Examples
    sl                                   # a train
    sl -l                                # a little one
    sl -F                                # it flies
    sl -a                                # an accident

## Options
-a    an accident: people cry for help
-l    a little locomotive
-F    it flies
-c    C51 instead of D51

## Notes
- Ctrl-C does not stop it. It ends when the train has passed.
