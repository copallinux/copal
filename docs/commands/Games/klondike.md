# command:  klondike
# purpose:  Klondike solitaire, in a terminal, with the keyboard.
# why:      Part of the catalogue's BSD games: patience for a terminal session.
# see:      ttysolitaire

## Use
The standard patience: build the foundations up by suit from the aces,
moving cards between the seven columns in descending, alternating
colours. Keys name the piles; the screen lists them.

## Examples
    klondike                             # play

## Options
(none)

## Notes
- The keys are shown on the screen as you play; `?` if they are not.
- `ttysolitaire` is the same game drawn with box characters, and it
  counts passes through the deck.
