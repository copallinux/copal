# command:  dump1090
# purpose:  Decode aircraft transponder broadcasts (ADS-B, 1090 MHz) from an RTL-SDR.
# why:      The catalogue's plane tracker: a dongle and a 1090 MHz antenna show
#           the aircraft overhead -- call sign, altitude, speed, position.
#           This is FlightAware's dump1090-fa.
# see:      rtl_test

## Use
Run it with the dongle attached; it prints each message it decodes. With
`--net` it serves the data to other programs; with `--write-json` it
writes files a web map can read.

## Examples
    dump1090                             # decode and print, from dongle 0
    dump1090 --net --quiet               # serve on the usual ports, print nothing
    dump1090 --write-json /tmp/adsb --quiet   # aircraft.json for a map
    dump1090 --gain 40 --lat 51.5 --lon -0.1  # set gain and your position

## Options
--net              serve data on ports 30001-30005
--net-only         network only, no dongle
--write-json DIR   write aircraft.json and friends into DIR
--gain DB          tuner gain
--freq HZ          another frequency (default 1090 MHz)
--lat / --lon      your position, for surface positions and range
--quiet            print nothing to the terminal
--metric           metres and km/h

## Notes
- This build has no `--interactive` table; for a live view, `--write-json`
  and a map page, or another program reading `--net`'s port 30003.
- A 1090 MHz antenna matters more than anything else: the dongle's own
  whip hears aircraft a few kilometres away, a tuned one hundreds.
- The dongle needs `plugdev` and the TV driver kept off it, as for
  rtl_test.
