# command:  7z
# purpose:  7-Zip: pack and unpack .7z, zip, tar and more, and extract rar, iso and dozens of others.
# why:      The catalogue's universal archiver: the best compression of the
#           common formats, strong encryption, and it opens nearly any archive
#           someone sends you -- rar included.
# see:      zip, bsdtar, unarj

## Use
A command letter, the archive, then files. `x` extracts with folders,
`a` adds, `l` lists. It detects the format of what it opens.

## Examples
    7z x archive.rar                     # extract, keeping folders
    7z l archive.7z                      # list the contents
    7z a backup.7z ~/Documents           # a new .7z of a folder
    7z a -p -mhe=on secret.7z plans/     # encrypted, names hidden too
    7z x image.iso -oiso-files           # the files inside an ISO
    7z t archive.zip                     # test it for damage

## Options
a       add to an archive (creating it)
x       extract with full paths
e       extract everything into one folder
l       list
t       test integrity
-o DIR  extract into DIR (written -oDIR, no space)
-p      set or ask for a password
-mx=N   compression level, 0 to 9
-m{...} other method settings: -mhe=on encrypts the file names too (.7z)

## Notes
- The command here is `7z`; guides that say `7za` or `7zr` mean the
  same program.
- `-o` takes its folder with no space: `-oout`, not `-o out`.
- It reads rar archives but cannot create them.
